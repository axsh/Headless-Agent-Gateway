# mcp-session-tools

Demonstrates Tern Client API session tools: `mcp_servers` and `functions`.

## Prerequisites

- A running Tern server (for example `examples/minimal-server`)

## Run

```bash
go run ./examples/mcp-session-tools --server http://localhost:3100 --work-dir /path/to/workspace
```

## HTTP equivalents

See `docs/ReferenceManual-WebAPIs.md` sections Create Session / Get Session / Update Session and [MCP and local functions](../../docs/ReferenceManual-WebAPIs.md#mcp-and-local-functions).
